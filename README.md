# Simulatore Mutuo

## About / Descrizione

**EN** — A mortgage simulator to compare different bank offers and plan early payoff with tax deductions.

**IT** — Un simulatore di mutui per confrontare diverse offerte bancarie e pianificare l'estinzione anticipata con detrazioni fiscali.

## Features / Caratteristiche

**EN**
- Compare multiple mortgage scenarios side-by-side
- View detailed amortization schedules with accumulated savings
- Calculate early closure with monthly savings and tax deductions
- Interest deductions: 19% of interest paid (max €760/year)
- Renovation deductions: 36% of costs (max €96,000) spread over 10 years
- Export amortization table as CSV
- All data persists in browser localStorage

**IT**
- Confronta più scenari di mutui fianco a fianco
- Visualizza piani di ammortamento dettagliati con risparmi accumulati
- Calcola la chiusura anticipata con risparmi mensili e detrazioni fiscali
- Detrazioni interessi: 19% degli interessi pagati (max €760/anno)
- Detrazioni ristrutturazione: 36% dei costi (max €96.000) in 10 anni
- Esporta il piano di ammortamento in CSV
- Tutti i dati persistono nel localStorage del browser

## Quick Start

### Prerequisites
- Node.js 16+

### Development

```bash
# Install dependencies
npm install

# Start dev server
npm run dev
```

Open http://localhost:5173/ in your browser.

### Build

```bash
npm run build
```
